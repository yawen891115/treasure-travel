# Static Boston interview demo
Deploy index.html unchanged to static hosting. No keys, login, backend or external dependencies.
All six fixture records are authored demo assumptions, not UCSD-derived data. Landmark names are geographic references; coordinates are approximate. Gallery is explicitly fictional. Hours/costs/durations are synthetic and prominently labeled.
The JavaScript greedy algorithm calculates walking legs with haversine distance, visits/waiting, group cost, opening windows, deadline and per-leg constraints. Follow-up buttons update live form state and rerun it. No fake LLM/chat. Not the Python runtime itself: portable browser implementation of the same constraint-planning approach, not a reuse of offline benchmark claims.
